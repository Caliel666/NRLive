DLSSNR-AMD setup for NRLive
===========================

NRLive runs DLSSNR through OpenNR's DLSSNR runtime (mochizuki's DLSSNR-AMD Vulkan runtime with
OpenNR's additions). The runtime and its shaders are in the opennr folder of this package.
NVIDIA model weights are not redistributed; extract them from your own nvngx_dlssnr.dll 310.9.16.

1. Obtain your own nvngx_dlssnr.dll version 310.9.16 from a legitimate installation. It contains
   both the original model and the newer small/fast model.
2. Extract the models with the extractor from mochizuki's DLSSNR-AMD Windows release
   (https://gitlab.com/mochizuki0323/DLSSNR-AMD/-/releases, model-tools folder; see its README).
   You need dlssnr-small.bin (New / Fast model) and/or dlssnr.bin (Original model).
   If OpenNR is already installed in a game, the same files are in that game's dlssnr-amd folder.
3. Put them in a dlssnr-amd folder beside NRLive.exe:
     dlssnr-amd\dlssnr-small.bin
     dlssnr-amd\dlssnr.bin
   NRLive links them into opennr\dlssnr-amd on first use (no copy).
4. Start NRLive, open the overlay, click NR, then open Settings > DLSSNR.
5. Use the model button to choose Original or New / Fast. Changing models rebuilds the network.
   The new model is faster and can produce a slightly different picture. INT4 mixed is only
   supported by the original model and also needs dlssnr-int4.bin (see opennr\README.md).

The two model files have different network layouts. Do not rename one to the other.

The runtime uses NRLive's current motion-vector texture and processes the captured render-resolution
image before the upscaler. The first use spends extra time building the network; let it finish before
judging performance. This is experimental and targets AMD RDNA4 GPUs (RX 7000 runs an experimental
network). Keep anti-cheat protected online games closed while testing injected or external graphics tools.

If a model file or the runtime is missing, NRLive leaves the captured frame unchanged and reports
the missing file.
